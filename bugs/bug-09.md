# BUG-09: “Хуучин хувилбар” линк 500 алдаа өгнө

Орчин: Уншлагын жагсаалт v2.0, Google Chrome 155.0.8059.80, Windows 11, 2026-10-20

Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асаасан (анхны 3 ном).

## Дахин гаргах алхам

1. `http://localhost:3000` хуудсыг нээнэ.
2. “Хуучин хувилбар” линкийг дарна.

Хүлээгдэж байсан: `/old` хуудас алдаагүй нээгдэнэ.

Бодит үр дүн: `/old` дээр `Internal Server Error` харагдаж, HTTP `500 Internal Server Error` буцна.

Ноцтой байдал: **Major** — хэрэглэгчид харагдах навигацийн линк бүрэн ажиллахгүй байна.
