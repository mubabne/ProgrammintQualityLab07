# BUG-02: Он баганын утгууд мянгатын таслалтай харагдана

Орчин: Уншлагын жагсаалт v2.0, Google Chrome 155.0.8059.80, Windows 11, 2026-10-20

Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асаасан (анхны 3 ном).

## Дахин гаргах алхам

1. `http://localhost:3000` хуудсыг нээнэ.
2. Он баганын утгуудыг харна.

Хүлээгдэж байсан: Онууд `1971`, `2008`, `1999` гэсэн энгийн бүхэл тоогоор харагдана.

Бодит үр дүн: Онууд `1,971`, `2,008`, `1,999` гэж таслалаар форматлагдсан байна.

Ноцтой байдал: **Minor** — өгөгдөл байгаа ч спецификацид заасан форматыг зөрчсөн.
