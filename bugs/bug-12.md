# BUG-12: “Нэмэx” товчны сүүлийн үсэг латин x байна

Орчин: Уншлагын жагсаалт v2.0, Google Chrome 155.0.8059.80, Windows 11, 2026-10-20

Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асаасан (анхны 3 ном).

## Дахин гаргах алхам

1. `http://localhost:3000` хуудсыг нээнэ.
2. Ном нэмэх товчны бичвэрийг харна.

Хүлээгдэж байсан: Товч `Нэмэх` гэж кирилл `х` үсгээр зөв бичигдэнэ.

Бодит үр дүн: `Нэмэx` гэж латин `x` (`U+0078`) ашигласан байна.

Ноцтой байдал: **Cosmetic** — ажиллагаанд нөлөөлөхгүй ч хэрэглэгчид харагдах үсгийн алдаа.
