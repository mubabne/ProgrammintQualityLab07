# BUG-01: “Нийт ном” тоолуур бодит мөрөөс нэгээр их байна

Орчин: Уншлагын жагсаалт v2.0, Google Chrome 155.0.8059.80, Windows 11, 2026-10-20

Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асаасан (анхны 3 ном).

## Дахин гаргах алхам

1. `http://localhost:3000` хуудсыг нээнэ.
2. Хүснэгтийн мөр болон “Нийт ном” утгыг харьцуулна.

Хүлээгдэж байсан: Хүснэгтийн 3 мөртэй тэнцэж “Нийт ном: 3” харагдана.

Бодит үр дүн: Хүснэгт 3 мөртэй боловч “Нийт ном: 4” харагдана. Бүх номыг устгахад 0 мөрийн хажууд “Нийт ном: 1” болдог.

Ноцтой байдал: **Major** — жагсаалтын үндсэн хураангуй үргэлж буруу тоо харуулж байна.
